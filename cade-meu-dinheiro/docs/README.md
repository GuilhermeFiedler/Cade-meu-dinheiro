# Documentação técnica – Cadê meu dinheiro?

Equipe: Guilherme T. Fiedler e Clara Meister

**Problema:** as pessoas não sabem para onde o dinheiro vai, porque pequenos gastos passam despercebidos e as ferramentas existentes são complexas demais.

**Solução:** um aplicativo web mobile-first em que o usuário registra gastos em poucos toques e vê um resumo mensal por categoria. O diferencial é ser extremamente simples e **não conectar a nenhum banco**: todos os dados são digitados pelo próprio usuário.

**Escopo do MVP:** cadastro e login, registro de gasto, histórico com edição e exclusão, total do mês e gráfico por categoria. Ficam para depois: metas e limites, lembretes, comparação entre meses e categorias personalizadas.
