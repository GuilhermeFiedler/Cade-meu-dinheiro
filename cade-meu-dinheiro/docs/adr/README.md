# 4. Registros de decisão de arquitetura (ADRs)

Um ADR aprovado não é reescrito. Quando uma decisão muda, o ADR antigo fica como histórico, com o status **Substituído**, e um ADR novo explica o que mudou e por quê.

| [ADR-003](ADR-003-backend-supabase-vercel.md) | Supabase como backend e Vercel como hospedagem | Substituído pelo ADR-007 |
| [ADR-004](ADR-004-registro-manual.md) | Registro manual de gastos, sem integração bancária | Aprovado |
| [ADR-005](ADR-005-frontend-react-vite-javascript.md) | Frontend em React com Vite (JavaScript), separado do backend | Aprovado |
